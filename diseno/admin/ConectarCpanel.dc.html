Sin https:// ni puerto. Usamos el 2083 con TLS.
Lo cifra el servidor y solo lo usa el sistema de monitoreo. Después de guardarlo nadie del equipo lo vuelve a ver.
Cómo crear el token en el cPanel del cliente
  1. Entra al cPanel y abre Seguridad » Administrar tokens de API » Crear.
  2. Nombre: dkoding-monitor. Así se distingue de cualquier otro.
  3. Vencimiento: deja el de un año. No se puede cambiar después; te avisamos 30 días antes.
  4. Copia el token: cPanel solo lo muestra una vez.
El token tiene el mismo alcance que la cuenta de cPanel. Úsalo solo aquí y revócalo si el cliente deja de trabajar con DKODING.
Todas las llamadas salen de la IP fija del servidor de copias de DKODING [IP del relay]. Si el hosting tiene firewall, pide que la permitan. Nunca se conecta desde tu navegador.
